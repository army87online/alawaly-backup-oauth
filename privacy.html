Privacy Policy

Al-Awaly Backup is a private backup system used by Al-Awaly Company.

The application uses the Google Drive API solely to store and manage encrypted FileMaker Server backup data in the Google Drive account authorized by the administrator.

The application does not sell, share, or distribute Google user data to third parties.

Backup data is encrypted before being stored in Google Drive. Access can be revoked at any time through the Google Account security settings.
